# Flower Bouquet Shop UI/UX Design

## Project Overview

This project presents a modern UI/UX design prototype for an online flower bouquet shopping application. The design focuses on providing a simple, attractive, and user-friendly experience that allows customers to browse flower collections, view product details, manage their cart, and place orders effortlessly.

## Features

- Modern and Clean User Interface
- User-Friendly Navigation
- Product Browsing
- Flower Details Page
- Shopping Cart Design
- Checkout Flow
- Responsive Layout
- Interactive Prototype

## Design Goals

- Improve user experience
- Create an attractive shopping interface
- Simplify the ordering process
- Enhance customer engagement

## Tools Used

- Figma
